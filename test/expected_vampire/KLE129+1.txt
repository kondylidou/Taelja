Axiom 2: forward_diamond(X,divergence(X)) = divergence(X)
Axiom 3: domain(X) = antidomain(antidomain(X))
Axiom 4: forward_diamond(X,Y) = domain(multiplication(X,domain(Y)))

Lemma 5: forward_diamond(X,Y) = antidomain(antidomain(multiplication(X,antidomain(antidomain(Y)))))
Proof:
  forward_diamond(X,Y)
= { by axiom 4 }
  domain(multiplication(X,domain(Y)))
= { by axiom 3 }
  antidomain(antidomain(multiplication(X,domain(Y))))
= { by axiom 3 }
  antidomain(antidomain(multiplication(X,antidomain(antidomain(Y)))))
