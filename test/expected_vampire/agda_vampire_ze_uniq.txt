Axiom 1: plus(ze,X) = X
Axiom 2: plus(neg(X),X) = ze
Axiom 3: plus(plus(X,Y),Z) = plus(X,plus(Y,Z))
Axiom 4: sK1 = plus(sK0,sK1)

Lemma 5: plus(X,Y) = plus(neg(neg(X)),Y)
Proof:
  plus(X,Y)
= { by axiom 1 R->L }
  plus(ze,plus(X,Y))
= { by axiom 2 R->L }
  plus(plus(neg(neg(X)),neg(X)),plus(X,Y))
= { by axiom 3 }
  plus(neg(neg(X)),plus(neg(X),plus(X,Y)))
= { by axiom 3 R->L }
  plus(neg(neg(X)),plus(plus(neg(X),X),Y))
= { by axiom 2 }
  plus(neg(neg(X)),plus(ze,Y))
= { by axiom 1 }
  plus(neg(neg(X)),Y)

Lemma 6: plus(neg(X),plus(X,Y)) = Y
Proof:
  plus(neg(X),plus(X,Y))
= { by axiom 3 R->L }
  plus(plus(neg(X),X),Y)
= { by axiom 2 }
  plus(ze,Y)
= { by axiom 1 }
  Y

Goal 1: sK0 = ze

  plus(neg(neg(sK0)),ze)
