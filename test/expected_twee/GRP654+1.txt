Axiom 1: mult(X,ld(X,Y)) = Y
Axiom 2: ld(Z,mult(Z,A)) = A
Axiom 3: mult(X,mult(Y,mult(X,B))) = mult(mult(mult(X,Y),X),B)
Axiom 4: rd(mult(X,Y),Y) = X
Axiom 5: mult(rd(X,Y),Y) = X

Lemma 6: mult(X,mult(ld(X,Y),mult(X,Z))) = mult(mult(Y,X),Z)
Proof:
  mult(X,mult(ld(X,Y),mult(X,Z)))
= { by axiom 3 }
  mult(mult(mult(X,ld(X,Y)),X),Z)
= { by axiom 1 }
  mult(mult(Y,X),Z)

Lemma 7: mult(mult(X,Y),ld(Y,Z)) = mult(Y,mult(ld(Y,X),Z))
