Axiom 1: less_equal(divide(divide(X,Y),divide(Z,Y)),divide(divide(X,Z),Y))
Axiom 2: less_equal(A,B) => divide(A,B) = zero
Axiom 3: less_equal(divide(a,b),d)
Axiom 4: less_equal(zero,A)
Axiom 5: less_equal(A,B) /\ less_equal(B,A) => A = B
Axiom 6: divide(zero,A) = zero
Axiom 7: less_equal(divide(A,B),A)
Axiom 8: divide(A,A) = zero
Axiom 9: divide(A,B) = zero => less_equal(A,B)

Lemma 10: divide(divide(a,b),d) = zero
Proof:
  have less_equal(divide(a,b),d)
    by axiom 3
  hence divide(divide(a,b),d) = zero
    by axiom 2

Lemma 11: less_equal(divide(divide(a,d),divide(b,d)),zero)
Proof:
  less_equal(divide(divide(a,d),divide(b,d)),zero)
= { by lemma 10 R->L }
  less_equal(divide(divide(a,d),divide(b,d)),divide(divide(a,b),d))
= { by axiom 1 }
  true

Lemma 12: divide(divide(divide(divide(a,d),b),divide(divide(b,d),b)),divide(divide(divide(a,d),divide(b,d)),b)) = zero

Lemma 13: zero = divide(divide(a,d),divide(b,d))

  have less_equal(zero,divide(divide(a,d),divide(b,d)))

   and less_equal(divide(divide(a,d),divide(b,d)),zero)

    by axiom 5

Lemma 18: divide(divide(a,d),b) = divide(divide(divide(a,d),b),zero)

Lemma 19: divide(divide(a,d),b) = zero
Proof:
  divide(divide(a,d),b)
= { by lemma 18 }
  divide(divide(divide(a,d),b),zero)
= { by axiom 6 R->L }
  divide(divide(divide(a,d),b),divide(zero,b))
= { by lemma 13 }
  divide(divide(divide(a,d),b),divide(divide(divide(a,d),divide(b,d)),b))
= { by lemma 18 }
  divide(divide(divide(divide(a,d),b),zero),divide(divide(divide(a,d),divide(b,d)),b))
= { by lemma 15 R->L }
  divide(divide(divide(divide(a,d),b),divide(divide(b,d),b)),divide(divide(divide(a,d),divide(b,d)),b))
= { by lemma 12 }
  zero
