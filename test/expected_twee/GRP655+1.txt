Axiom 1: mult(rd(X,Y),Y) = X
Axiom 2: mult(Z,mult(A,mult(B,A))) = mult(mult(mult(Z,A),B),A)

Axiom 4: mult(Z,ld(Z,A)) = A

Lemma 6: ld(rd(X,Y),mult(mult(X,Z),Y)) = mult(Y,mult(Z,Y))
Proof:
  ld(rd(X,Y),mult(mult(X,Z),Y))
= { by axiom 1 R->L }
  ld(rd(X,Y),mult(mult(mult(rd(X,Y),Y),Z),Y))
= { by axiom 2 R->L }
  ld(rd(X,Y),mult(rd(X,Y),mult(Y,mult(Z,Y))))
= { by axiom 3 }
  mult(Y,mult(Z,Y))
